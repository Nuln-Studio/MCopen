# MCOpen
一款简约轻量化开源 Minecraft‑Java版 启动器，纯净、无广告

## 简介
兼容原版 / Forge / Fabric / NeoForge
支持微软正版OAuth登录（开发中）、离线单机游玩
> 本项目属于第三方工具，和Mojang、微软无官方关系

## 启动方式
### 编译成品（项目大重构暂时不可用）

运行，直接运行 `MCO.exe`

### 源码运行
命令行入口文件：`CliOpen.py`

## 快速开始

### 命令行快速开始
1. 程序自动扫，定位 `.minecraft` 游戏根目录
2. 程序扫描 versions 文件夹读取全部可用游戏版本
3. 输入序号选定版本
4. 扫描缺失资源文件（但是不会自动下载ᗜ⩊ᗜ），启动Minecraft

## 常见问题
1. **扫描不到游戏版本**
检查versions内每一个版本文件夹，必须包含版本json配置文件
2. **游戏启动失败**
可以尝试配置对应游戏版本适配的Java运行环境，或者库缺失以及索引文件缺失（都有提示）
